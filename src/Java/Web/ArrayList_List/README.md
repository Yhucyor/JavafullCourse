** Array khó khăn trong việc xác định số lượng phần tử ** 

 * List (Bản thiết kế): Nó là một Interface – giống như một bản hợp đồng hoặc bản thiết kế quy định rằng một danh sách thì phải làm được gì (phải xếp theo thứ tự, cho phép chứa các món đồ giống nhau, cho phép tìm đồ theo vị trí).

 * ArrayList (Sản phẩm thực tế): Đây là một Class (Lớp cài đặt) làm đúng theo bản thiết kế của List. Nó sử dụng cấu trúc mảng động để lưu trữ dữ liệu thực tế.
